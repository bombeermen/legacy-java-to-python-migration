# Вправа 2: міграція Java → Python (FastAPI) через Claude API

Тренування на оголошенні «Python Developer: Migrate Legacy Java/PHP Projects to Python and Integrate AI/LLMs».
Без клієнта, без Connects. Ліміт часу: 2 години від першого запуску коду.

## Що демонструємо

Мігрувати невеликий legacy Java 8 застосунок (розрахунок рахунків з бізнес-правилами) у Python,
використовуючи LLM, і **довести тестами, що поведінка збігається** з оригіналом.

Критерій готовності: скрипт друкує частку збігів на 192 тестових рахунках між Java-еталоном
(`cases/golden.txt`) і згенерованим Python. Ціль: 192 з 192, включно з помилковими випадками.

## Кроки

1. [x] Legacy Java 8 застосунок, 192 тестові рахунки, еталонний вихід (`cases/golden.txt`)

3. [x] `migrate.py`: Java-код у Claude Haiku, отримати `billing.py`

7. [x] README і публікація на GitHub
